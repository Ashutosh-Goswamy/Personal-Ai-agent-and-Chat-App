# AI Collaborative Code Editor

A real-time collaborative AI-powered code editor built using the MERN stack, Socket.io, Redis, and Google Gemini AI.

---

## Features

- JWT Authentication
- Real-time Chat
- Multi-user Collaboration
- Google Gemini AI Integration
- AI Code Generation
- Dynamic File Creation
- Live File Editor
- Redis Integration
- REST APIs
- Responsive UI

---

## Tech Stack

### Frontend

- React.js
- Tailwind CSS
- Axios
- Socket.io Client

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.io
- Redis
- JWT
- Google Gemini AI

## Installation

### Backend

```bash

```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
